Функциональные назначения

Выберите возможности управляющего модуля. Комплектация оборудования будет сформирована автоматически.

Можно выбрать несколько способов доступа.

Комплектация оборудования

Для каждого выбранного физического назначения выбрана модель по умолчанию. PIN не требует отдельного оборудования и использует дисплей.

Состав строк зависит от выбранных функциональных назначений. Для назначения без моделей в каталоге сначала добавьте подходящую модель в каталог оборудования.
